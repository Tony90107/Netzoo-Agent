# Held-out set 8: comparison design and claim kind

## How it was written

An isolated subagent wrote this set on 2026-10-04 using only the task brief. It did not open any project file, verification rule, earlier set, agent output or model API. There are 32 prompts:

- **Families R1-R6** (6 x 4 = 24 prompts). In each family, all four prompts share the same data sentence and have different purpose sentences. Every family has at least one control whose claim is `none`.
- **Standalone traps T1-T8** (8 prompts):
  - T1-T3 are negation traps.
  - T4-T8 are precision traps.

Each prompt is one paragraph: a data sentence followed by a purpose sentence, 34-44 words, with no tool names. The labels use the vocabulary from the brief. `acceptable_candidates` follows the input table of the registered tools. `heldout.json` was generated by a script, which also checked these properties:

- the JSON parses;
- each `prompt` equals `data_sentence + " " + purpose_sentence`;
- the 32 ids are correct;
- every prompt is 25-45 words long;
- no prompt names a tool;
- the coverage rules hold.

**Family designs:** 2 paired, 3 groups, 1 none.

**Claim counts across all 32 prompts:**

| Claim kind | Prompts |
|---|---|
| `group_difference` | 4 |
| `individual_change` | 5 |
| `regulator_change` | 5 |
| `causal` | 3 |
| `prediction` | 4 |
| `none` | 11 |

## Family themes (one line each)

- **R1** (paired; sample-sheet columns and sequencing lanes): human CD14+ monocytes before and 6 h after one prednisolone dose.
- **R2** (groups; littermates/litters and pooled libraries on one run): Ucp1-knockout vs wild-type mouse brown fat.
- **R3** (paired; two omics layers on every biopsy): hidradenitis suppurativa, lesional vs perilesional skin from the same patients, RNA-seq plus methylation arrays.
- **R4** (groups; tanks and technical replicate libraries): rainbow trout liver at three ethinylestradiol doses.
- **R5** (none; batches, lanes, normalization and batch correction, bookkeeping columns): dental pulp from extracted third molars.
- **R6** (groups; no technical detail): granulosa cells from women with PCOS vs ovulatory controls. Two purposes ask about miRNAs.

## Trap themes (one line each)

- **T1** (negation; prediction deferred at the start of the purpose): meningioma series sequenced in batches. Labels: none / none.
- **T2** (negation; comparison with controls ruled out at the end of the data sentence): Graves' disease patients at diagnosis and at remission. Labels: paired / individual_change.
- **T3** (negation; causal claim disclaimed at the end of the purpose): shrimp lines resistant vs susceptible to white spot virus. Labels: groups / regulator_change.
- **T4** (precision; replicate wells over plates, plus the words "baseline" and "reference"): one iPSC-derived hepatocyte line. Labels: none / none.
- **T5** (precision; each RNA split into two aliquots sequenced at two depths, plus "compared with the rest"): sheep rumen epithelium. Labels: none / individual_change.
- **T6** (precision; "paired" means ATAC and RNA from the same samples): mouse E11.5 limb buds. Labels: none / none.
- **T7** (precision; "predicted target genes" is not a prediction goal): Parkinson's PBMC case-control data from two clinics. Labels: groups / none.
- **T8** (precision; litters recorded only as a blocking factor, plus "directed map ... regulate"): mouse olfactory epithelium. Labels: none / none.

## Labelling judgement calls (please review)

1. **Priors.** When a prompt states expression data, I counted the tools that need EXPR+MOTIF+PPI as acceptable, on the assumption that motif and PPI priors come from public resources. This is less clear for trout (R4) and shrimp (T3), where no standard motif prior exists.
   - miRNA tools (PUMA, LIONESS-PUMA) are listed only where the purpose mentions miRNAs (R6-a, R6-d).
   - DRAGON and LIONESS-DRAGON are listed only where two omics layers are stated (R3, T6).
2. **R2, knockouts vs littermates.** Labelled `groups` (genotype), with litters treated as blocks. Someone could argue for a matched-littermate (paired) reading. The data sentence does not pair animals one to one.
3. **R2-a.** Labelled `causal` because the user wants to "demonstrate that Ucp1 loss causes". A knockout is a real manipulation, so the expected answer says that the networks are associative, and that any causal argument rests on the experiment and on analyses outside the suite.
4. **R4.** "Eight fish per tank" probably means one tank per dose, so tank is confounded with dose. The prompt is still labelled `groups`. The technical replicate libraries are not treated as units.
5. **Controls inside designed families (R1-d, R3-d, R4-d, R2-d, R6-d).** The design label stays as the data sentence states it (paired or groups), even though the purpose wants only one pooled or descriptive network.
6. **Prediction purposes without a recorded outcome (R3-b, R5-d).** These are still labelled `prediction`. The expected answer should point out that outcome labels are needed. R6-b (flag PCOS in a new patient) is diagnostic classification, which I also labelled `prediction`.
7. **T2.** Labelled `paired` because each patient was sampled twice. The negated comparison is only the one against healthy controls.
8. **T5.** "Compared with the rest of the flock" is labelled `individual_change` with design `none`. The aliquot split is a technical depth check, not "one sample split between treatments".
9. **T7.** Labelled design `groups` because the data sentence states a case-control cohort, even though the purpose ignores it. Claim is `none`.
10. **T8.** "Directed map of which TFs regulate which genes" is labelled `none`, not `causal`.
11. **R5-a.** Clustering into subtypes is labelled `none`, as the brief says. The mutation-based subtyping tool is not acceptable because the data has no mutations.
