## 順帶發現：執行句被讀成獨立的需求

這和 A1′ 無關，兩組都有。

R 組的 DO 題中，有 6 份讀取被判 PARTIAL，等於部分拒絕：

| 讀取 | 被判「做不到」的需求列 |
|---|---|
| Y05 ×2 | 「I'd like you to run LIONESS-PUMA on them.」 |
| Y20 ×2 | 「Could you run PANDA on these three files?」 |
| Y09 | 「saved under results/aml_lioness/」 |
| 主回合 Y22 | 「keeping the default lam and gamma」 |

- 原因：要求執行的那一句（點名方法，沒有說結果），或輸出路徑、沿用預設的那一句，被讀成獨立的結果列。它們不提供任何東西，所以判為做不到，整題變成 PARTIAL。
- 同一題的另一列，已經把結果正確採信給同一個方法。
- 這是 R 組形狀（方法和結果分在兩句）的另一面：A1′ 處理目標那一側，需求列這一側則會產生誤拒。
