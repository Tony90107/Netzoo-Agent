- regulatory_all: one regulatory network (TF or miRNA to gene) built from all the samples together -- COBRA, GIRAFFE, OTTER, PANDA, PUMA
- regulatory_per_sample: a separate regulatory network (TF or miRNA to gene) for each sample -- LIONESS-PANDA, LIONESS-PUMA
- coexpression_per_sample: a separate gene-gene co-expression network for each sample -- BONOBO, LIONESS-COEXPRESSION
- covariate_coexpression: how covariates such as group, batch or age change gene co-expression -- COBRA
- tf_activity: each transcription factor's activity in each sample -- GIRAFFE
- two_layer: a network linking two kinds of omics data, such as RNA and methylation -- DRAGON, LIONESS-DRAGON
- communities: modules or communities in a regulator-gene network -- CONDOR
- subtypes: patient subtypes from somatic mutations -- SAMBAR
