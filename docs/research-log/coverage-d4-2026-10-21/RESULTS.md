## 結論：D4 在現行讀題形狀下幾乎沒有空間，不建議做

| | 現行讀題形狀（p4b 以後與 h1–h4，520 份） | 舊回合（p0–p5 等，290 份） |
|---|---|---|
| 句子：有被欄位引用／只被當背景／完全沒被碰到 | 974／83／**7** | 511／39／11 |
| 含數字的地方：有被欄位引用／只被當背景／完全沒被碰到 | 731／30／**6** | 357／10／0 |
| 有金標的讀取中，判錯 | 81 | 90 |
| 其中留有沒被碰到的句子或數字 | **3**（J32、J44、H40） | 6 |

- **現行讀題已經幾乎不漏句。** 讀題 schema 規定每一句都要填（Log 387：strict 模式下每一句都是必填欄位），這本身就是 D4 想做的「涵蓋率保證」。沒被碰到的句子只有 0.7%。
- **已有的重讀（Log 406）只再補到 5 句**（35 → 30，全部回合合計）。
- **81 份判錯中，最多只有 3 份可能跟「沒讀到的字」有關：**
  - J32：沒被讀到的是目的句「I'm hoping something interesting falls out of it」，這正是金標「請說清楚」的依據。這是唯一可能有關的一份。
  - J44：沒被讀到的「Start it now.」和錯誤無關。
  - H40：0.001 和 5,000 是設定值，但錯誤原因不在沒讀到數字（見下）。
- **只被當背景的數字也不是錯誤來源。** 例如 C23 的「24 hours」是取樣時間點，C11 的「44 AD, 44 controls」是組別人數，C48 的「2023 recruitment wave」是收案批次，都不影響判斷。
- **舊回合的 10 份未碰到的句子，幾乎都是表達目的或不確定的句子**，例如 C09、C10、C26、C37、C36。這類句子現在已經有對應的欄位。

量測方法：句子用 `request_sentences` 切；數字包含阿拉伯數字和數字詞，排除檔名裡的數字。數字詞會誤判，例如句首的「One」，所以表中「含數字的地方」只計阿拉伯數字。判斷用的是目前程式的 B2 判斷（`usage-fields-2026-10-21/harness-after.json`）。

## 量測時發現的真正大宗：部分執行，加上兩套金標的衝突

現行讀題形狀中，金標「不能做」卻判「做」的有 13 份，其中 **7 份是部分執行**：J44、H18、H27、H40、L13、L21、p5r C08。這就是 audit 中 7 份 `L4_partial_overcredit`。分兩類：

1. **附屬的部分被當成一項可以做的分析：**
   - H18：「Can you set it up that way?」
   - H27：「Write the output to condor_tpm/」
   - L13：「Per-sample edges to … and the cohort matrix to …」
   - 這三份的主要分析都做不到，但附屬句被算成一項可以做的分析，結果變成部分執行。
   - 這屬於文獻回顧 D1 的 molecular 單位問題：附屬句應該掛在它所屬的分析上。Codex 10/21 曾修過，但 codex-split 時連同 `requirement_role`／`parent_quote` 一起拿掉了。
2. **run 的設定做不到時，兩套金標的判法相反：**

| 金標集 | 題目 | 請求 | 金標判斷 |
|---|---|---|---|
| a24b（10/14 最終驗收，逐句評分） | MX05 | 「fit GIRAFFE …, but set its regularisation lambda to 0.5」 | run 可做、設定不可做（部分執行） |
| a24b | MX04 | 「run OTTER … on the GPU」 | run 可做、GPU 不可做（部分執行） |
| h3（10/18–19，四種判斷） | L21 | 「run GIRAFFE …, but change the optimizer: learning rate …」 | 不能做 |
| h2 | J44 | 「set computing to gpu」 | 不能做 |
| h1 | H40 | 「GIRAFFE … with a custom learning rate of 0.001, 5,000 iterations」 | 不能做 |

- MX05 和 L21 幾乎是同一個請求，金標卻相反。
- 現行的 `settings_apart` 是依 a24b 的金標設計的，所以 h 系列的這幾題一定判錯。
- 要用哪一種判法，需要你決定；決定之後再調整規則，或更新其中一套金標。
